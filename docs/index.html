How to use this version

  1. Export the Tally purchase register and sales register to .xlsx or .csv.
  2. Download GSTR-2A, GSTR-2B and GSTR-1 files from the GST portal, then upload each in Import files.
  3. Upload the Tally purchase register as Books - Purchase Register and the sales register as Books - Sales Register.
  4. Review and correct the column mapping before importing.
  5. Open Invoice reconciliation, choose a comparison, and run it.
  6. Export the result to Excel and review exceptions before taking any ITC, tax, or filing decision.
  7. In GSTR-3B summary, enter the portal and books totals and export the comparison.
  8. Use the same GSTIN and period for all related files. Period format is MMYYYY, e.g. September 2026 = 092026.

Important limitations

  • It does not connect to a GSP or download returns automatically.
  • Portal export formats vary. Column mapping must be checked; complex multi-sheet or JSON exports may need format-specific handling.
  • GSTR-3B is summary-level and is compared by totals, not by invoice number.
  • Matching uses invoice number + party GSTIN. Credit/debit notes, amendments, reverse-charge cases, ISD, imports, duplicate invoice numbers and credit notes need more specialised logic.
  • A match in this report does not itself establish ITC eligibility or legal compliance. Verify exceptions against the original documents and current rules.
  • Data is stored unencrypted in this browser profile. Use a trusted device, and clear local data when you are done if the machine is shared.
